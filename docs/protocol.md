# Frozen transport protocol

The full panel uses 150 question/source blocks from each of Wikipedia, abstracts and recipes, plus 500 separate human controls per source-domain bundle. Direct prompts used source titles, not the original human prose. The full 3×3 matrix includes same-model rewriting, with a separate human-origin rewrite category. Source, domain and task jointly differ from the earlier question-answer pilot; this is not a pure causal source intervention.

Four classical detectors and two published scoring methods retain their earlier frozen parameters and thresholds. RADAR is a separately calibrated seventh detector. Calibration uses 500 disjoint human-only texts and strict exceedance of order statistic 476 for a marginal 5% target under exchangeability. That target is not a universal or source-conditional 5% guarantee.

The reported cell family has 357 members. Each source/condition/model/detector rate receives a Bonferroni-adjusted exact binomial interval, assuming independent question blocks within that cell. Pooled counts spanning models or sources remain descriptive and receive no new independent-binomial confidence statement.

The planned primary endpoint requires a detected parent, an undetected rewrite, independent semantic-fidelity judgment and valid completion within 100–128 words. The two directional comparisons concern Gemma-to-Qwen versus Gemma-to-Gemma under Binoculars and Fast-DetectGPT. The primary result remains pending because the independent human ratings and adjudication are absent. Raw flips and mechanically valid flips are not this endpoint.

The release retains all completed length failures, refusals and adverse detector results. They are not unrun work and are not replacement targets. Human-process, watermark and architecture-causal claims are outside this experiment.
